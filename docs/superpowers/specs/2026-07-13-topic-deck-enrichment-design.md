# Topic Deck — Full Presentation Redesign + Content Enrichment

**Date:** 2026-07-13
**Status:** Design (awaiting review)
**Owner:** carsonbk

## Goal

Turn the 30-day roadmap's topic lessons into a real **full-screen, interactive slide
presentation** (PowerPoint-like), as polished and varied as the reference mockup
[`docs/mockups/topic-slides-shopping-mockup.html`](../../mockups/topic-slides-shopping-mockup.html) —
**not** the current small card-in-the-middle screen. Two halves:

1. **Presentation shell redesign** — full-screen dark stage, PPT-style slide layouts, clickable
   progress dots, prev/next nav, and keyboard control (← / → / Enter).
2. **Content enrichment** — reuse the existing PrepVocab words + example sentences and expand
   them with AI-generated content into more varied, practical slides. Generalizes across all
   20 topics.

## Context

- Decks are stored one-per-day in `topic_days.slides` (a **JSONB** column) and rendered by
  [`src/components/topics/TopicDeckRunner.tsx`](../../../src/components/topics/TopicDeckRunner.tsx),
  which switches on `slide.type` and delegates to per-slide components under `src/components/topics/`.
- **Today's shell is the problem the user called out:** a fixed dark overlay with a single centered
  `max-w-xl` white card, a thin progress bar, and a Continue/Skip button *inside each slide*. No prev,
  no keyboard, no clickable dots, no presentation layout. It "still looks like the old version."
- Decks are generated by [`scripts/generate-topic-decks.mjs`](../../../scripts/generate-topic-decks.mjs).
  Vocab/example slides come straight from PrepVocab word rows; attribute/dialogue/voice_qa + the cover
  goal are Groq-generated. Persona: a Vietnamese software engineer aiming to work/interview at
  multinational companies (frames scenarios; **all output English**).
- Word rows provide: `id, term, meaning_vi, example_en, image_url, phonetic_uk, pos, audio_url`.

## Decisions (locked)

1. **Full-screen PPT presentation shell** (not the current small card). See "Presentation shell" below.
2. **Theme: dark**, matching the current Learn/flashcard session (`bg-neutral-900`). PPT layout, dark palette.
3. **Navigation: free** (PPT-style). ← / → / Enter and clickable dots always move between slides;
   interactions inside a slide are optional and never block navigation.
4. **Language: English only.** The only Vietnamese kept is each word's `meaning_vi` on vocab cards.
   No Vietnamese glosses on sentences/phrases/dialogue.
5. **Images: reuse PrepVocab `image_url`.** No bespoke illustrations. The "labeled parts" spotlight slide
   is dropped. Two-column layouts fill their art panel with a representative PrepVocab image; fallback is
   a subtle gradient + a large topic emoji/icon.
6. **Scope: Approach A** for content — add `warm_up` + `phrases`; enhance `voice_qa` + `recap`; keep
   vocab/example/attribute/cover/dialogue (restyled).
7. **Recap rewards: XP + speaking score + streak.**

## Presentation shell (the core redesign)

Rework `TopicDeckRunner` into a full-screen deck player. Dark theme throughout.

**Layout (desktop, lg+):**
```
┌───────────────────────────────────────────────┐
│ [X exit]   Day N · <Title>            (top bar) │
│ ●●●○○○○○  ○  ○                    3 / 12  (track)│
│ ┌───────────────────────────────────────────┐  │
│ │  STAGE  (max-w ~1040px, aspect 16/9)        │  │
│ │  eyebrow · KICKER                           │  │
│ │  Big heading                                │  │
│ │  lead text / two-column content / art       │  │
│ └───────────────────────────────────────────┘  │
│ [ ◀ Prev ]                        [ Next ▶ ]    │
└───────────────────────────────────────────────┘
```
- **Top bar:** exit `X` → `/topics`; a day chip "Day N · <title>".
- **Track:** one clickable dot per slide (done / active / upcoming states) + a "i / n" counter.
  Replaces the thin progress bar.
- **Stage:** a bordered, rounded, shadowed panel. On `lg+` it holds a fixed `16/9` aspect ratio so
  slides feel like presentation slides; on mobile it becomes auto-height and scrolls. Slide transitions
  keep the existing Framer-Motion slide/fade (`AnimatePresence`).
- **Nav bar:** `◀ Prev` (ghost, disabled on slide 0) + `Next ▶` (primary). On the last slide (recap),
  Next reads "Back to path" and exits.
- **Keyboard:** `ArrowRight`/`Enter` → next, `ArrowLeft` → prev. **Guarded:** ignored when focus is in a
  `textarea`/`input`/contenteditable (so typing an answer, and pressing Enter in the voice answer box,
  never advances the deck).

**Slide UX model change:** slides no longer render their own Continue/Skip/Done button. Each slide
renders *only* its presentation content + in-slide interactions. Global nav advances. Consequences:
- The voice slide reports its grade through an `onScore(score: number)` callback; the runner accumulates
  scores. (Unanswered voice slides simply contribute nothing.)
- Reaching the **recap** slide triggers `finishTopicDay(dayNo, scores)` once, so recap can render real
  XP/streak/score. The separate "finished" overlay is removed; recap *is* the rewards screen. (Kept only as
  a fallback if a deck somehow has no recap slide.)

**Shared presentation primitives** (new, `src/components/topics/slide-ui.tsx`) so every slide shares the
PPT look on dark: `SlideEyebrow` (kicker with accent tick), `SlideHeading` (h1/h2 scale), `SlideLead`,
`SlideTwoCol` (content + art column, stacks on mobile), and `ArtPanel` (renders a PrepVocab image or the
gradient+emoji fallback). Dark tokens: surface `neutral-800`, lines `white/10`, accent `green-500`,
AI accent `violet-400`, muted text `neutral-400`.

## New deck order

```
cover · warm_up(NEW) · vocab ×≤2 · example ×≤2 · attribute ×≤2 · phrases(NEW) · dialogue · voice_qa ×≤2 · recap
```
≈ 12–13 slides/day. Any slide whose generation fails is omitted; the deck still runs.

## Data model

No DB schema migration (`slides` is JSONB). Add to [`src/types/index.ts`](../../../src/types/index.ts):

```ts
export interface WarmUpTopicSlide {
  type: "warm_up";
  scenario_en: string;   // 1–2 sentences setting a real situation for this topic
  agenda: string[];      // 3–4 short lesson-step labels
}
export interface PhraseGroup { heading_en: string; phrases: string[]; } // heading = situation, 2–3 phrases
export interface PhrasesTopicSlide { type: "phrases"; groups: PhraseGroup[]; } // 2 groups
```
Add both to the `TopicSlide` union. `TopicDeck`/`TopicDaySummary` unchanged (their `title_vi` is unused
by the UI now; left to match the DB row).

**Recap rewards data:** extend `finishTopicDay(dayNo, scores)` in
[`src/lib/actions.ts`](../../../src/lib/actions.ts) to return
`{ xpEarned: number; currentStreak: number; bestScore: number }` (streak from the `user_streaks` row it
already upserts; bestScore from `user_topic_progress`). Pass the next day's title into the runner as
`nextDayTitle: string | null` (already available to the topics API/page) for the "unlock" line.

## Rendering — components

New:
- **`slide-ui.tsx`** — the shared dark PPT primitives above.
- **`WarmUpSlide.tsx`** — eyebrow "Warm-up", heading, `scenario_en` as lead, `agenda` as a numbered list
  with staggered animation; two-column with an `ArtPanel`.
- **`PhrasesSlide.tsx`** — eyebrow "Key phrases", each `PhraseGroup` as a card (heading + phrases); tapping
  a phrase plays TTS (`speakText`), mirroring the mockup.

Restyled to the new primitives + de-buttoned (nav handled globally):
- **`CoverSlide`** — presentation cover: eyebrow, big title, `goal_en` as a goal chip, hero image in `ArtPanel`.
- **`VocabSlide`** — grid of tap-to-reveal cards (term / phonetic / `meaning_vi`) + audio (largely as-is, restyled).
- **`ExampleSlide`** — the word's `example_en` featured with its image; audio.
- **`AttributeSlide`** — MC chips with correct/wrong states + `explain_en` reveal (as-is, restyled).
- **`DialogueSlide`** — keep reveal-line-by-line + per-line audio; relabel speakers "You" / "Colleague";
  the "Next line" reveal stays an *in-slide* control (distinct from global deck nav).
- **`VoiceQASlide`** — mic + editable transcript; on grade show a **score ring** (conic gradient),
  an encouraging headline by score band, and key-point chips as hit (✓) / miss (grey). Reports via `onScore`.
- **`RecapSlide`** — checklist from slide types actually present; rewards row (XP · speaking score % · 🔥 streak);
  "🔓 Unlock Day N: <title>" when a next day exists.

`TopicDeckRunner` — rewritten shell (top bar, dots, stage, nav, keyboard) with the free-nav model,
score accumulation, `finishTopicDay` on reaching recap, `warm_up`/`phrases` branches, and safe handling of
unknown slide types (render nothing) so legacy decks still play.

## Generation

Extend [`scripts/generate-topic-decks.mjs`](../../../scripts/generate-topic-decks.mjs) — same single
Groq call/day, English-only — to also return:
```jsonc
"warm_up": { "scenario_en": "<1-2 sentences>", "agenda": ["...","...","...","..."] },
"phrases": [ { "heading_en": "<situation>", "phrases": ["<en>","<en>"] },
             { "heading_en": "<situation>", "phrases": ["<en>","<en>"] } ]
```
Prompt rules: `agenda` 3–4 items; `phrases` exactly 2 groups × 2–3 phrases; English only; grounded in the
topic + its vocabulary. Normalize with existing helpers + a new `normPhraseGroups`/`normAgenda`. Assemble in
the new order; omit any missing/invalid piece. Regenerate all 20 decks: `--force`.

## Error handling / safety

- Generation: per-piece validation; invalid pieces skipped, deck still saved; existing 429/503 retry kept.
- Runner: only known slide types render; unknown ignored → **legacy decks keep working**.
- Keyboard nav guarded against form-field focus (no accidental advance while typing).
- `finishTopicDay` failure is non-fatal (recap shows best-effort/zero values).

## Testing

- **Unit (vitest):** `normPhraseGroups`, `normAgenda` (valid/partial/garbage); deck-assembly order helper
  (parsed generation → correct sequence with missing pieces omitted).
- **Component (vitest + RTL):** `WarmUpSlide`/`PhrasesSlide` render content and (phrases) call `speakText` on tap;
  `RecapSlide` shows reward tiles + unlock line (present when `nextDayTitle` set, hidden when null);
  `TopicDeckRunner` — dots/counter reflect index; ← → move; Enter advances but is **ignored while a textarea is focused**.
- **End-to-end (manual, `verify` skill):** generate one day (`--day 4`), open `/topics/4`, drive the full deck
  with keyboard + dots, confirm full-screen dark PPT look, warm-up → phrases → dialogue → voice → recap, and
  recap XP/score/streak.

## Out of scope

- Bespoke per-item illustrations / the "labeled parts" spotlight slide.
- Touch swipe gestures (nav via buttons + dots on mobile; can be a later add).
- Any Vietnamese translation of sentences/phrases/dialogue.
- Light/auto theme (dark only for now).
- Changes to the SRS topic-review flow, XP formula, or the words/lessons schema.
- The `describe` size/scale picker (shopping-specific).
